# Proposal

## Why

Cristian autorizou em 29/10/2026 uma demo pública de portfólio, sem conta ou servidor. A demo existente preserva os fluxos aprovados, mas ainda não tem publicação, seed pedagógico integrado nem armazenamento separado para a apresentação pública.

## What Changes

- Oferecer modo público estático com exemplos pequenos, datas úteis e roteiro opcional de três ações.
- Preservar alterações do visitante e restaurar os exemplos com confirmação, sem tocar o armazenamento local anterior.
- Publicar somente a demo no GitHub Pages do repositório existente, com assets no subdiretório correto.
- Conferir os fluxos professora/aluno/decisão, documentar a entrega e suas limitações.

## Capabilities

### New Capabilities

Nenhuma.

### Modified Capabilities

- `demo-workspace`: modo público isolado, exemplos restauráveis, navegação e operação estática sem serviços reais.

## Impact

Demo React, seed e armazenamento locais, build Vite, workflow GitHub Pages, testes e documentação. Identidade visual atual preservada. Piloto autenticado e B4 continuam independentes; nenhum dado real é publicado.
