## Há alguma pergunta bloqueando a base agora?

Não. As respostas são suficientes para documentar a visão e ordenar as entregas. A primeira funcionalidade ainda terá uma especificação própria antes de receber código.

## Quando reabrir esta lista

Se surgir necessidade de turmas, menores, vários fusos, integração obrigatória desde o início, importação de dados ou mudança do público, registrar a pergunta e o impacto antes de redesenhar a solução.

Não transformar detalhes como cores, campos obrigatórios e posição de botões em bloqueios de arquitetura.
