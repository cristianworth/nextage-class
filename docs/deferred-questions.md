# Perguntas para a hora certa

Status: abertas. Esta lista não representa requisitos aprovados. Os exemplos são informais para facilitar uma conversa com a professora. Resolver apenas o que a próxima entrega exigir e levar a resposta para a especificação correspondente.

| ID | Quando resolver | Pergunta |
| --- | --- | --- |
| LATER-01 | Primeiro cadastro | “Quais dados você realmente precisa para começar um aluno? Telefone, ocupação e interesses podem ficar para depois?” |
| LATER-02 | Primeira aula e datas | “Qual cidade/fuso usamos como referência dos horários? A data de início das aulas pode ser diferente do cadastro?” |
| LATER-03 | Primeiro registro | “Que parte do registro o aluno pode ler? Precisamos separar observação privada e resumo compartilhado?” |
| LATER-04 | Primeiro registro | “Você costuma lançar a aula no dia ou também precisa voltar e registrar uma anterior?” |
| LATER-05 | Recorrência | “Quando muda o horário fixo, até quando geramos as aulas? Como trata férias e feriados?” |
| LATER-06 | Remarcação | “Ao trocar esta e as próximas, o que fazemos com aulas futuras que já tinham sido remarcadas individualmente?” |
| LATER-07 | Faltas e edição | “O motivo de falta pode ficar vazio? Como você quer corrigir um lançamento feito errado?” |
| LATER-08 | Homework | “Pode passar mais de um homework? A correção pode ser parcial ou basta marcar como corrigido?” |
| LATER-09 | Preparação | “Você escolhe o material da próxima aula antes ou costuma decidir na hora?” |
| LATER-10 | Acervo e demo pública | “Vamos criar material próprio para o projeto, cadastrar links ou usar algum conteúdo que você tem autorização para compartilhar?” Demo usa conteúdo fictício/autoral; não pressupor acesso ao acervo do sistema atual. |
| LATER-11 | Portal do aluno | “Se o aluno mudar de nível, ele continua vendo o material do nível anterior?” |
| LATER-12 | Solicitação de horário | “Aluno pede uma aula avulsa ou um horário semanal? Você sempre confirma antes de entrar na agenda?” |
| LATER-13 | Layout da demo | “No celular, uma lista do dia resolve? No computador, quais informações precisam aparecer no bloco da aula?” |
| LATER-14 | Piloto real | Confirmar forma de convite/login, recuperação de conta, dados necessários, retenção, backup e recuperação. |

| LATER-16 | Progresso | “O que módulo significa na sua rotina? Vale acompanhar sequência de presença ou só progresso do conteúdo?” |

Perguntas resolvidas não devem continuar como pendência: registrar a resposta no requisito da mudança ou em `decisions.md`, conforme o alcance da decisão.
